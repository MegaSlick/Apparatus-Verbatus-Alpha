# Attestatores

The witnesses report.

Each witness reads every page the Exemplar sealed and reports what it perceived:
Chandra and Churro read the whole page, and DAI reads each record its own detector
found on it. Reports are unverified, of uncertain and unequal quality, and never
final. They are always retained, one page Testimonium per page and witness.

Read [CONTRACT.md](CONTRACT.md) for what this stage writes and where. That document
is the interface — no other stage reads this one's code.

See the root [ARCHITECTURE.md](../../ARCHITECTURE.md) for how this fits the flow,
and [GLOSSARY.md](../../GLOSSARY.md) for the vocabulary.
