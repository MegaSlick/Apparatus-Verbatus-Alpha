# Attestatores

The witnesses report.

Each witness reads the sealed page and reports what it perceived: Chandra and Churro
read the whole page, and DAI reads each record its own detector found on it. Each page
reading also gives a view of every act whose first page it is. Reports are unverified,
of uncertain and unequal quality, and never final. They are always retained.

Read [CONTRACT.md](CONTRACT.md) for what this stage writes and where. That document
is the interface — no other stage reads this one's code.

See the root [ARCHITECTURE.md](../../ARCHITECTURE.md) for how this fits the flow,
and [GLOSSARY.md](../../GLOSSARY.md) for the vocabulary.
