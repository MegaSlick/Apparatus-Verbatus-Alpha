# Review

Where items the Recensor could not resolve reach Tyrel.

It lives inside the Recensor because the Recensor is what fills this queue.
Separating the queue from the stage that fills it is how things get lost.

This queue preserves unresolved items; it is not a picker and does not establish or rewrite
text. Suspected fabrication or a poor reading is held for Tyrel, never re-rolled until a
preferred wording appears.
