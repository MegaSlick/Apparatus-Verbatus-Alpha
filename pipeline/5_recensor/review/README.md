# Review

Where items the Recensor cannot resolve will reach Tyrel. **Nothing is built here yet:
this directory holds this README and no queue.**

It will live inside the Recensor because the Recensor is what fills the queue.
Separating the queue from the stage that fills it is how things get lost.

The queue will preserve unresolved items; it is not a picker and will not establish or
rewrite text. Suspected fabrication or a poor reading is to be held for Tyrel, never
re-rolled until a preferred wording appears.
