# Designator

Publishes the page evidence the page reading uses.

On every sealed page it publishes Surya's line and block census and the record
detector's records and their crops. None of it decides an act or establishes
text: the Perlector reads each whole page and names the acts itself.

Read [CONTRACT.md](CONTRACT.md) for what this stage writes and where. That document
is the interface — no other stage reads this one's code.

See the root [ARCHITECTURE.md](../../ARCHITECTURE.md) for how this fits the flow,
and [GLOSSARY.md](../../GLOSSARY.md) for the vocabulary.
