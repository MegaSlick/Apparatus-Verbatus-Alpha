# Perlector

R5a adds the retained prior-draft protocol: universal `lectio-prior`, optional
`primed-without-prior` control, and the production Perlectio. They are separate
artifact kinds and attempt operations. Nuda remains its own un-fed instrument.
Only the explicitly `primed-with-prior` Perlectio may cross the Archetypus
boundary.

Reads the ink and establishes the text.

Reads the ink itself, using the testimonia as clues that sharpen its own reading and never as options to choose between. Where it produces several readings it reconciles them itself, against the image. It reads through to the end — truncation is a failure, not an output.

Per spec 08: every reading is built from a persisted **dossier** (regions, downscaled
page renders, every testimonium verbatim with factual-only witness context, under a
run-sealed named/blinded regime), classified for **truncation** by a declared
instrument rather than assumed, and compared against each witness on **derived
comparison views** rather than raw-string voting. A separate, sampled **Lectio
nuda** instrument reading carries no testimonia and is structurally outside every
consumer that establishes text — a different artifact kind entirely, never
`kind="perlectio"`. `uncertain_spans` and `gaps` are the two annotation layers over
one clean `text`; a gap is zero-width by construction, so testimony evidence is
always linked beside the text and never inside it.
