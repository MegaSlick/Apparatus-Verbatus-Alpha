# history

Dated records of what happened. **Evidence, never instructions.**

Nothing here binds anything. If a document in this folder tells you what to do,
it is out of date by definition. The six root documents define the project and
session rules; the tracked agent, skill, hook, and workflow files implement or
specialize those rules without outranking them.

This directory exists so that dated material has somewhere to go that is not the
working documentation. The old repository had no such place, and 320 markdown files
is what happened.
